## 3. الذكاء الاصطناعي

| القرار | القيمة |
|---|---|
| الافتراضي للتطوير | `mock` |
| أول مزود حقيقي | OpenAI عبر طبقة `ai-core` |
| القيود | الفهم واستخراج الكيانات فقط — ممنوع التسعير أو تأكيد الحجز |

---

## 4. مزودو السفر

| القرار | القيمة |
|---|---|
| الافتراضي للتطوير | Mock Provider معلن وواضح |
| أول مزود حقيقي لاحقًا | Amadeus عبر Adapter |
| المبدأ | لا اعتماد تصميمي على Amadeus وحده؛ كل مزود خلف Adapter |

---

## 5. نطاق الـ MVP التشغيلي

| الموضوع | القرار |
|---|---|
| الحملات | مبسّطة داخل الـ MVP (قائمة + قالب + جدولة أساسية) |
| المدفوعات | تسجيل حالة يدوي فقط في الـ MVP — بدون بوابة دفع مبكرة |
| خدمات البحث الأولى | طيران كمسار أساسي + عقود/Mock لبقية الخدمات |
| الواجهة | عربية RTL أولًا |

---

## 6. البيانات والمال

| القرار | القيمة |
|---|---|
| تخزين المبالغ | Integer بالوحدة الصغرى (هللة/سنت) مع `currency` |
| منع float | إلزامي |
| التكلفة/الربح | داخلي فقط؛ لا يُرسل للعميل |

---

## 7. الأمن والعزل

| القرار | القيمة |
|---|---|
| عزل Tenant | `organizationId` على مستوى التطبيق والاستعلامات والطوابير |
| PostgreSQL RLS | مؤجّل لما بعد استقرار الـ MVP |
| العمليات الحساسة | صلاحيات صريحة + Audit Log (+ موافقة ثانية اختيارية لاحقًا) |

---

## 8. الطوابير

| المكتبة | BullMQ |
