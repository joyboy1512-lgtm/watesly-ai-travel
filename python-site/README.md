# WeekendGate — نسخة بايثون

نسخة محلية من متجر WeekendGate مكتوبة ببايثون من البحث حتى تأكيد الحجز. شكل الصفحات أيضاً مبني في بايثون داخل `weekendgate/views.py` و `weekendgate/theme.py`.  
لا تتصل بالموقع المنشور `www.weekendgate.com` ولا تعدّل عليه ولا تستخدم مفاتيح Hotelbeds أو Duffel.

## ماذا تغطي

- الصفحة الرئيسية والوجهات والعروض وصفحات عن الشركة والتواصل والسياسة.
- بحث الفنادق: وجهة، تواريخ، غرف، اسم، نجوم، إلغاء مجاني، إفطار، مرافق، نوع المكان، سقف السعر، المسافة.
- ترتيب الفنادق: الأنسب، السعر، التقييم، المسافة. معادلة «الأنسب» نفسها المستخدمة في المتجر: `(التقييم × 12 + النجوم × 8) × 100000 / السعر`.
- بطاقة الفندق والخريطة فوق التصفية. شكل الصفحات مكتوب في بايثون (`weekendgate/views.py` و `weekendgate/theme.py`) وليس نسخاً لملفات CSS الخاصة بالموقع المنشور.
- صفحة الغرفة واختيار السعر، ثم ملخص الحجز برقم مثل `WG-A1B2C3`. الحجز يبدأ «بانتظار الدفع» أو «الدفع في الفندق»، ولا يُؤكد قبل تسجيل الدفع.
- بحث الطيران: مسار، درجة، توقفات، ناقل، ترتيب، ذهاب فقط أو ذهاب وعودة.
- الأنشطة وتوصيل المطار.
- العربية والإنجليزية مع اتجاه الصفحة، والأرقام دائماً لاتينية ورمز العملة بعدها.
- العملات: KWD SAR AED BHD OMR QAR USD EUR، والأسعار محفوظة بالدينار.
- حساب المسافر، المسافرون المحفوظون، وحجوزاته.
- لوحة تشغيل محلية: الملخص، الحجوزات وإلغاؤها، العملاء، مصدر الكتالوج المحلي، ونسبة الزيادة على السعر.
- مساعد نصي يحوّل جملة مثل «فندق في دبي» إلى صفحة النتائج.

الكتالوج مدمج داخل `weekendgate/catalog.py` حتى تعمل النتائج بدون إنترنت خارجي. قواعد التصفية والسعر في `weekendgate/search.py` و `weekendgate/money.py`.

## التشغيل

```bash
cd python-site
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

ثم افتح `http://127.0.0.1:8080`.

دخول المسافر التجريبي: `guest@watesly.travel` / `Guest1234!`  
دخول لوحة التشغيل: `demo@watesly.travel` / `Demo1234!`

الحجوزات تُحفظ في `weekendgate/data/weekendgate.sqlite` على جهازك. احذف الملف لمسح البيانات. توقيع الجلسة يُحفظ في `weekendgate/data/secret` ويُنشأ عند أول تشغيل.

## ما أضافه التطوير

ما زال كل هذا داخل بايثون، وعلى الكتالوج المحلي فقط:

- المخزون ينقص عند إتمام الحجز، ويعود عند الإلغاء. السعر يختفي من النتائج إذا لم تبق غرف أو مقاعد كافية.
- تسجيل الدفع من صفحة التأكيد دفتر محلي. لا يتصل ببنك أو كي نت، ولا يخصم من مزوّد.
- إلغاء الحجز متاح لصاحب الحجز من حسابه، ومن صفحة التأكيد، ومن لوحة التشغيل.
- نسبة الزيادة تُضبط من لوحة التشغيل وتُطبَّق على الإقامة والطيران والأنشطة والتوصيل. إضافة الطفل 5 د.ك عن كل ليلة.
- نماذج الإرسال تحمل رمزاً يطابق ملف تعريف الارتباط، حتى لا يُقبل طلب مجهول.
- كلمة المرور تُملَّح عشوائياً، ومرجع الحجز لا يُشتق من عدد الصفوف.

النسخة لا تتصل بـ Hotelbeds أو Duffel ولا بالموقع المنشور. المصدر الظاهر في لوحة المزوّدين هو كتالوج بايثون المحلي.
